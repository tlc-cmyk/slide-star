# 滑管星

用伸縮號吹《一閃一閃》、《兩隻老虎》、《歡樂頌》同《藍色多瑙河》——一隻喺瀏覽器即玩、以橫向畫面為主嘅節奏小遊戲。上下移動調音高，按住就吹；走音會發出不準的伸縮號聲。

線上試玩：<https://tlc-cmyk.github.io/slide-star/>

## 點玩

1. 打開 `index.html`（或上面嘅 GitHub Pages 連結），喺標題畫面揀一首曲。會先有一小段預備拍子。
2. **上下移動**指針或手指，跟住譜面由右向左行過嚟嘅音符調音高（上高下低）。
3. **按住**就吹：滑鼠掣、空白鍵／F／J，或者手指按住畫面。鬆手即停聲。手機用一隻手指就得：上下係音高，接觸就係吹。
4. 伸縮號永遠跟住而家嘅音高發聲。吹錯音高唔會變成失敗提示音，而係發出走音嘅伸縮號聲。想即興吹都可以。
5. 評分睇你吹嗰陣，音高有幾贴近每個音符，同埋係咪準時開始同放開。連續吹準會累積連擊；走音或者音符中間靜咗就會斷。
6. 一次吹大約五秒就要換氣：氣錶見底會被迫停大約半秒，之後可以再吹。喺音符之間短短鬆手就可以換氣。
7. 吹完會見到分數、最長連擊同評級。

如果手機直立，畫面會提示「請將手機橫過來玩」，並盡量將橫向舞台縮放喺畫面入面。標題、演奏同結果畫面都有靜音掣。

## 操作一覽

| 操作 | 作用 |
| --- | --- |
| 上下移動 | 調音高（上為高音，下為低音） |
| 按住滑鼠／觸控／空白鍵或 F、J | 吹奏 |
| 鬆手或放開按鍵 | 停聲 |
| 「聲音：開／關」 | 靜音或開聲 |

## 評級

準確度（按每個音嘅音準同吹奏覆蓋計算）：

| 準確度 | 評級 |
| --- | --- |
| 95 或以上 | 首席 |
| 85 或以上 | 好手 |
| 70 或以上 | 合格 |
| 40 或以上 | 練習 |
| 其餘 | 噪音 |

判定用字為「超準／準／尚可／走音／靜咗」。如果破咗自己嘅最佳紀錄，會顯示「自我最佳更新」。最佳分數存在瀏覽器 localStorage。

## 樂曲

四首旋律都屬於公眾領域（public domain），由本遊戲自行記譜；伴奏全部係原創嘅簡單鋼琴／撥弦和聲（I–IV–V 或類似進行）。預備拍子之後先入曲。全部曲目一開始已經解鎖。

- 第一首《一閃一閃》（Twinkle Twinkle Little Star）：C 大調，100 BPM，約 29 秒，以級進為主。
- 第二首《兩隻老虎》（Frère Jacques）：C 大調，108 BPM，約 36 秒，反覆一次。
- 第三首《歡樂頌》（貝多芬《歡樂頌》主題）：C 大調，100 BPM，約 38 秒。
- 第四首《藍色多瑙河》（約翰·施特勞斯二世《藍色多瑙河》著名主題）：D 大調，3/4 拍，120 BPM，約 56 秒。只採用眾人熟悉嘅公眾領域旋律開頭同主題，並非模仿任何現有遊戲嘅編曲。

## 技術

- 單資料夾靜態網頁：`index.html`、`style.css`、`engine.js`、`audio.js`、`render.js`、`game.js`，無建置步驟、無外部 CDN。
- 畫面用 Canvas 即場繪製（原創平面畫風：校園風格吹號者、金色膠囊音符、每首曲目不同嘅簡單背景）。
- 聲音用 Web Audio（自訂銅管波形、震盪器同濾波器）合成，唔靠取樣檔。
- 玩法邏輯集中喺 `engine.js`，可以用 Node 做無介面測試：

```bash
node test-engine.mjs
```

測試會檢查：完美機器人喺四首曲都應得到「首席」；完全唔吹應接近 0 分；走音機器人分數會低，但樂曲時間仍然走完。

## 來源說明

- 本遊戲係原創作品，包括標題「滑管星」、介面文案、程式、美術同合成音色，**並非**複製任何現有遊戲或網站嘅程式、圖像、角色、標誌、配色或文案。
- 玩法構想係「音高軸喺垂直方向、時間由右向左、按住先出聲」嘅伸縮號節奏練習；實作、畫面、聲音同所有用字全部重新設計。
- 《一閃一閃小星星》、《兩隻老虎》（Frère Jacques）、《歡樂頌》主題同《藍色多瑙河》著名旋律屬於公眾領域。伴奏為本遊戲原創。

## 本機開啟

用任何靜態伺服器都可以，例如：

```bash
cd slide-star
python3 -m http.server 8080
```

然後用手機或電腦瀏覽器打開提示嘅位址。直接用檔案協議打開 `index.html` 通常都可以玩（無需建置步驟）。
